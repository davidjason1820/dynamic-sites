# Dynamic Sites source registry

Dynamic Sites uses only the five repository URLs listed below as project source references. The requested URLs are preserved exactly as supplied; a redirect or canonical upstream repository must not be presented as belonging to the project owner.

| Role | Requested source URL | Use in Dynamic Sites | License boundary |
| --- | --- | --- | --- |
| Prompt archive | https://github.com/davidjason1820/motionsites.ai | 65 prompt records and prompt directions | The repository license is MIT, but embedded media and third-party assets require separate review. Prompt attribution is preserved in the catalog. |
| Parallax source | https://github.com/davidjason1820/infinite-scroll-with-parallax | Infinite scroll, Lenis/GSAP patterns, parallax and scrub concepts | Code is MIT. The README restricts bundled client-owned images to the tutorial repository and live demo; those images are not redistributed. |
| Clip menu source | https://github.com/davidjason1820/EaseReverseClipMenu | Clip-path menus, radial cover motion, video-menu behavior, and EaseReverse timing | Demo code is MIT. Bundled generated media is treated separately and is not redistributed by Dynamic Sites. |
| Three.js source | https://github.com/davidjason1820/littlesttokyo | Three.js/WebGL/WebGPU examples, shaders, post-processing, and 3D concepts | Three.js code is MIT. Individual examples and assets can have separate terms and must be checked before copying. |
| Fluid reveal source | https://github.com/davidjason1820/three-skull | WebGPU/TSL fluid reveal, bloom, scan-line, and loading concepts | Demo code is MIT. Bundled models/media are not treated as redistributable catalog assets. |

The catalog links to these sources for **View Source** and **Live Demo** actions. It does not claim ownership of any repository, asset, prompt, image, video, model, or third-party media.

## Core collection boundary

The application keeps its core collection separate from source inventories:

- 65 prompts
- 12 background videos/shaders/concepts
- 10 interactive UI components

The source ZIP resource inventory is used as schema and licensing guidance only. Its other source collections are not imported into this application because this build is restricted to the five repositories above.
