# Dynamic Sites

Dynamic Sites is a premium dark resource-discovery website and its single source-of-truth catalog repository.

The website includes search, filters, tags, pagination, bookmarks, saved resources, detail modals, copy actions, source links, live demos, license metadata, responsive desktop/mobile layouts, and the original DS visual system.

See [`RESOURCE_HUB_INSTRUCTIONS.md`](./RESOURCE_HUB_INSTRUCTIONS.md) for setup, catalog structure, counts, and licensing rules.
